# Product DNA Studio · 互动网页 + 研究后台

本版基于附件原型开发，保留三步流程和淡紫色视觉，新增真正的服务端持久化后台。当前是可运行的开发版本，尚未线上发布。分析仍是浏览器关键词建议，不是真实 LLM。

## 启动

需要 Python 3.11+，无第三方 Python 依赖。

```bash
cd product-dna-studio
# 将下面的示例替换为你自己的强密码；不要提交密码到代码仓库。
export DNA_ADMIN_PASSWORD='replace-with-your-own-long-password'
python server.py
```

互动网页：http://localhost:8080/

研究后台：http://localhost:8080/admin

可配置：`PORT`（默认8080）、`DNA_DATA_DIR`（默认项目下 data）、`DNA_COOKIE_SECURE=1`（HTTPS 部署时开启）。不要直接将 Python 开发服务器暴露在互联网上；正式服务需 HTTPS 反向代理、请求限流、稳定进程管理和持久磁盘。Sites 托管不运行 Python，迁移到该平台需 Worker API 和 D1 适配；本环境缺失 Sites 项目/发布助手，未创建或发布 Site。

## 使用流程

1. 参与者输入或上传经历，生成关键词建议，手动编辑地图，下载 PNG。
2. 填写姓名/昵称与可选联系方式，主动勾选保存同意，点击“提交副本给研究者”。
3. 后端将提交时的输入文字、产出结构、PNG 快照、UTC时间、同意版本保存到 SQLite；返回提交编号。
4. 你登录后台，查看记录、搜索和按状态筛选、查看原始输入与产出图像、复制产出、导出单条或全部 JSON、下载 PNG。
5. 标记待审核/已审核/待跟进，写下验证备注，必要时删除记录。

每次主动提交是独立快照；提交后的本地编辑不会覆盖旧记录。姓名/昵称为参与者自填，不是验证过的身份。本版不追踪未提交访客、不记录所有击键，也不统计未完成访问。后台显示提交数，同一个人可以提交多次。

## 数据与访问

- `data/studio.sqlite` 是真实持久化数据库；请为其准备持久磁盘并备份。JSON 导出含个人数据，应妥善保管。
- 未勾选同意无法提交。原始文件和语音不保存；会保存参与者主动提交的解析文字。
- 当前按说明保留至研究者删除，没有自动到期清理。研究者可按提交编号删除记录；备份中的副本需同时按自己的保留政策清理。
- 管理接口必须登录，使用 HttpOnly/SameSite cookie、8小时会话、跨来源写入校验和登录失败限速。会话在服务重启后失效。
- 后台不开放注册；密码由环境变量提供。正式多管理员或真实身份需求需后续接入账户与角色系统。
- 输入内容不写入 HTTP 日志；SQLite 查询使用参数。服务端请求上限约3.5MB。
- 不要把 data 目录、环境变量、真实参与者导出提交到版本控制。

## 已知边界

- 本地规则建议不保证识别全部能力；未匹配位置需手动填写，没有凭空补齐能力。未接入 LLM 或 API 密钥。
- PDF/DOCX 解析依赖公共 CDN；文件最大5MB，PDF最多处理15页，文本最大20,000字符，扫描PDF没有OCR。空白解析会报告错误。
- 语音依赖浏览器 SpeechRecognition 支持和其语音服务。
- 只提供真实 PNG 导出；已移除原型中将位图包装为 SVG 的入口。
- 此环境未提供所需 cua_repl.js，按 Sites 技能要求未进行浏览器预览，因此移动端、文件解析、语音与实际PNG视觉仍需浏览器验收。

## 验证

```bash
python -m unittest -v
```

集成测试覆盖：未登录拒绝、同意校验、提交保存、后台登录、原文及快照读取、跨来源拒绝、审核备注持久化、导出和删除。JavaScript 已通过 Node 语法检查。

## 后续产品验证

建议先邀请少量参与者测试，使用审核备注记录：建议是否准确、参与者改了什么、图像是否易读、是否愿意分享。下一步可接入真实AI、增加生成前后版本对比、明确保留期限和研究联系渠道，再决定公开推广方式。

## Render 部署准备

新增 Dockerfile、.dockerignore 和 render.yaml，适配现有 Python 服务。Render 连接前没有创建托管服务、产生部署或配置付费资源。Blueprint 使用 starter 与 1GB 持久磁盘，正式创建前需核对平台报价。数据库必须在持久磁盘 /data 中；不能用随部署清空的临时文件系统。后台密码由 Render 生成，只在平台环境变量设置中查看和管理，勿粘贴到公开代码或聊天中。公开首页为域名根路径，后台为 /admin。发布前仍需浏览器端验收并补充实际研究联系渠道。

## 免费体验版

`preview/index.html` 是不连接后台的独立体验版，可通过 Render Static Site 免费额度发布。只发布 preview 目录，不发布后台页面。支持本地文字/简历解析、关键词建议、编辑、PNG和JSON下载，不包含服务端提交、数据库、账号或AI接口。Render 的带宽和构建时间有免费额度限制。
