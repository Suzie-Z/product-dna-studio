A little clarity on privacy

Your PDF or DOCX is uploaded to our server and read in an isolated process. The original file is discarded after reading; it is not saved to disk or a database.

Extracted text, career facts and your corrections are sent to OpenAI for analysis. Common contact details are removed first, but automatic removal is not exhaustive. OpenAI and hosting providers apply their own processing and retention policies.

Your review and results are held in temporary server memory for up to ten minutes. The browser holds the selected file and results in memory until you replace them, restart or leave. There is no account, document library or public publishing.

If production counting is enabled, only anonymous creation totals and expiring random request receipts are stored, never CVs or results. Hosting may retain operational metadata such as network addresses.
