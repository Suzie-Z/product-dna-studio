# Limits, privacy and interpretation

- Source references and literal quotes prove provenance, not employment, qualifications, source truth or every semantic inference. Capability categories remain model interpretations. English instructions and independent bounds/script checks are not an exhaustive language/semantic verifier.
- The product targets PMs and concrete product transitions. It retains truthful prior roles. Common PM titles in several languages are recognised; ambiguous contexts can still require clarification. Appearance is selected independently of source demographics from the neutral avatar library.
- Supported MediaRecorder browsers send bounded in-memory recordings to the configured transcription API. Recordings are not written to app storage; provider retention policies still apply. Browser speech recognition is a compatibility fallback, with device/provider language limits. Real physical microphone quality remains device verification.
- PDF/DOCX/TXT parsing is browser-side, limited to5 MB and readable PDFs of15 pages or fewer. Legacy binary DOC requires conversion; scanned PDFs need OCR. Parsing can lose formatting or fail during CDN/network outages. Full CV previews are not shown.
- Up to30 session versions retain their original sources, maps, parent IDs and presentation in browser memory. Removing/replacing a pending upload does not rewrite the evidence of earlier versions. Refresh/navigation clears session history. Combined context is bounded to22,000 characters and32 source records, with18,000 per source.
- Server response replay retains request content in bounded memory for ten minutes, with timed eviction; it is never written to a personal-data database. Sources/maps are not intentionally logged. Contact redaction is not exhaustive. OpenAI receives text for interpretation and moderation. `store:false` is not zero provider retention; provider abuse-monitoring, prompt-cache and hosting/speech processing policies still apply.
- Public v2 counts represent server-ready initial creations, not unique humans, guaranteed browser views, satisfaction or billing. Identified internal tests, staging/local traffic, refinements, clarifications, failures and downloads are excluded. Undisclosed manual tests and bots cannot be distinguished from visitors without additional identity measures.
- Historical23-count aggregates include internal tests and cannot be reliably separated. They are preserved as unverified history, while a labelled new counter starts separately. Durable deduplication stores hashes of random request IDs, not CV/body/visitor hashes. Receipts expire after48 hours and are deleted on the next counter access. Retry identity is reused while input stays unchanged; a ten-minute response cache prevents repeated completed calls, and durable receipts prevent recounting within the receipt window after cache loss/restart.
- JSON requests are capped at240 KB, active model concurrency at two and network-address bursts at eight per minute. Proxied clients can share an address. The existing daily provider-attempt quota uses Australia/Sydney dates and process memory; it resets on service restart and is not a durable billing cap or ten unique users. A bounded repair consumes another provider attempt. Client cancellation stops waiting, not necessarily server processing.
- Scoped edits preserve undeclared fields by allowlisted merging, but user instructions still require model interpretation. Simple built-in theme/neutral-character changes use a deterministic no-model path. Complex arbitrary layouts and a manual map editor are not supported. No automatic fallback to a more expensive text/image model is enabled.
- The paired Sol/Astra benchmark is small and synthetic; it does not establish superiority for every complex CV; the current Astra selection follows the requested quality-first preference. Measured latency and token-based USD estimates vary with context, provider load, cache state and repairs. No universal duration or invoice guarantee is displayed.
- There is one responsive map and one landscape PNG per download:3200 pixels wide, with height set by actual content and date layout. Programmatic rounded-font outlines keep export typography consistent. Overflow blocks download rather than clipping. Some unusual future wording can still need a shorter rewrite through the composer.
- The self-contained HTML is approximately12 MB because illustration/font libraries are bundled. Free Render compute can cold-start. The existing free Postgres has its original30-day expiry; no paid storage or warming service was added. Trial scheduling and credentials remain unchanged.

V2 uses a quality-first two-stage pipeline. Astra costs more than the earlier single-call Sol flow; latency and cost depend on input size, provider load, caching and repairs. The unchanged10/day process-memory attempt quota includes extraction, summary, refinement and transcription calls, so it does not represent10 visitors or10 complete maps. It is not a durable account spending cap. API billing controls should also be set in the provider account.

Audio is transcribed in its original languages. Final map content remains English. Headless capture and synthetic English/Mandarin/mixed recordings verify the integration; physical microphones, accents, noisy rooms and every Safari/mobile version still need device testing. Legacy DOC and scanned-PDF OCR are not implemented; supported PDF/DOCX/TXT paths and clear conversion guidance remain.
