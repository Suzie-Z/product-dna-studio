# Limits and privacy

- A quote/reference check proves that a quoted passage came from submitted material. It does not verify employment, credentials, the truth of the source, or every semantic inference. Evidence status is an interpretation, not an accreditation badge.
- Model instructions and independent bounds/script checks target English output; locally edited exports also receive a per-field model language review; automated language judgments can still be imperfect. Review the artifact before sharing. Clinical, financial and other regulated qualifications are never independently verified.
- Input/source order is not assumed to be career chronology. Dates are shown only when supplied. When chronology is not identifiable, the map uses Experience Areas.
- No app database or intentional content logging is used. Drafts, source context, corrections and up to six undo snapshots stay in page memory; server copies exist only during requests. OpenAI Responses uses `store:false`, but provider abuse-monitoring/retention rules and hosting processing still apply. Moderation also sends text to OpenAI. Redaction of emails, long phone numbers, URLs, and labelled private details is not an exhaustive PII detector.
- Refinement needs source context because the server is stateless. A session consent checkbox explicitly allows resending it. Locally edited exports require a separate reviewed-edit consent and a server safety review. No edits silently become independently verified facts.
- Browser voice recognition uses the browser's configured language and third-party speech service. Automatic language detection and universal language/browser support are not promised. Typing, editable transcripts and CV input remain available. No audio files are stored or sent by the app itself.
- PDFs must contain readable text, at most 15 pages. No OCR or malware scanner is provided. PDF/DOCX/TXT file signatures/types and 5MB size are checked client-side; the API receives only bounded JSON text. DOCX extraction can lose formatting. CDN/network outages may prevent parsing.
- Maximum source content: 22,000 characters across up to 12 sources, 18,000 per source. Refinements are up to 1,500 characters. Each correction becomes a new source; very long sessions may need a new consolidated draft.
- JSON requests are capped at 240KB, concurrency at two, and network-address request bursts at eight per minute. Short-lived hashed address counters stay in process memory. Proxied clients can share an address; Origin checks are not authentication.
- The daily **AI generation/refinement/review attempt** cap is per process, uses Australia/Sydney dates, and resets on free-service restart. It does not identify ten unique people and is not a durable billing cap. Use OpenAI project spend controls/alerts; a strict quota needs durable counters or invitation/identity infrastructure.
- One bounded schema/evidence repair is allowed; retries consume the same daily budget. Transient provider errors are surfaced, not repeatedly retried. Client cancellation stops waiting; an upstream request may still finish and incur charges.
- Free Render compute can sleep/cold-start. No paid disk, database, background warming, analytics collector or external sharing is provisioned. The seven-day trial starts only when the owner sets `TRIAL_START_DATE`.
- Controlled icons and a single abstract neutral figure prevent arbitrary image prompts, likeness inference or uploaded artwork from entering the renderer. Text is moderated, but no automated safety system is perfect. Unsafe or unconfirmed material blocks the new artifact; a prior accepted map remains available during a rejected refinement.
- PNGs are portrait 2400×3000 or square 2800×2800. Layouts adapt to 1, 2, 3, 4 (2×2), or 5 (3+2) strengths. Text that still cannot fit gets an explicit preview fallback and download is blocked until shortened; no silent clipping or invented shortened copy.
- Only successful new-map generation is counted; clarification, failed attempts, refinement and export review do not increment it. No content or visitor identifiers are stored with counts. When COUNTER_DATABASE_URL is omitted, the visible count is labelled this server run and resets on restart. The optional free Postgres plan retains date/integer totals across app restarts, but expires after 30 days; export or migrate those aggregate counts before expiry. Failed counter writes do not discard a successfully generated map. These totals are usage observations, not unique visitor or billing counts.
