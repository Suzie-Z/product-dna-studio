# PM Career Studio handoff architecture

This enhances the existing native-Python/vanilla-JavaScript app. It does not replace the hero, upload/parser, transcription, source validation, stateless provider adapter, session history or aggregate database. The supplied four PNGs were reviewed as visual direction; none is stretched into a runtime layout.

P0: central UI copy, honest privacy fallback, compact1600×900 deterministic result scene, browser layout validation, readable content compression, natural-language copy/theme edits. P1: one shared visual manifest, six original SVG platform archetypes, four pathway renderers,24 existing coherent icons and semantic alternatives. P2: conversational context, immutable visual patch validation, cancellation/restore safeguards, actual foreground bounds, viewport/export regression and real API verification.

The canonical session revision remains `{map, sources, variant, intelligence, instruction, change_summary, parent_id}`. Factual map fields keep their existing evidence schema. Visual fields live in `variant`: theme, pathway, icon/platform overrides keyed by stable item IDs, avatar, mascot side/visibility, density, contrast, softness and decorations. This preserves compatibility with earlier source-backed maps. The original revision is retained alongside the latest29 revisions; refresh/navigation clears browser memory.

`preview/copy.json` is the user-facing copy source. `build_preview.py` escapes it and the shared `preview/visual-manifest.json` into the existing self-contained HTML. `visual_catalog.py` reads the same manifest on the server and defines the allowlisted typed visual patch branches. `semantic_refinement.py` receives current map/visual state, relevant evidence, the original visual and four recent edit turns. It separates content patches from visual patches and applies both immutably. Visual-only edits do not change facts, evidence or accumulate new CV sources. Exact simple legacy color/avatar requests retain the no-model fast path; freeform/mixed requests use Astra.

The manifest records semantics, shape variants and asset references. New platforms/pathways are original programmatic SVG, use the result palette and have no embedded text. Existing raster illustrations remain project assets; the rounded fonts retain their bundled SIL OFL files. The model selects approved icon keys for actual capability meaning, and can alter one or all keys; it cannot return arbitrary SVG, CSS, scripts or external URLs. Unknown asset identifiers receive neutral local fallbacks. No new image-generation request or external asset download is needed per result.

Desktop output is always16:9 and exports at3200×1800 with exact rounded-font outlines. Mobile/narrow layouts stack and can scroll. CSS sizes a result container against available viewport space rather than applying a global transform. At125%-equivalent reduced viewports vertical scrolling is permitted; no overlap/horizontal clipping is accepted. The renderer measures both layouts before a new revision replaces the current one. Overflow asks for bounded semantic shortening, never ellipsis/truncation or an in-image engineering message. A visual-only arrangement that cannot retain existing wording is declined with a useful message instead of silently rewriting the story.

No CV or map is written to the app database. Parsing stays in the browser; extracted text, relevant refinement context and microphone recordings are processed by the API/provider. Results/transcripts can remain in bounded server memory for10 minutes for retries. Counts and expiring random-request receipts are stored separately; hashed network burst limits are temporary memory only. Provider retention is governed by the linked policy. Therefore the UI uses the safe disclosure fallback, never an end-to-end zero-retention promise. Google Fonts requests were removed; app/map typography uses the existing bundled rounded fonts. The LinkedIn feedback URL is intentionally unset and its link hidden until a real owner-provided URL is configured.

Cancellation aborts the browser wait and an interaction epoch prevents stale responses or deferred fit passes from replacing the selected revision. An already-running provider call can still finish and incur usage; the backend transport does not offer job cancellation. Version restore and Undo preserve their exact visual settings.

Remaining deliberate boundaries: curated shapes/icons/layout controls, not arbitrary freehand grids or on-demand custom artwork; device-specific microphone/physical Safari testing; the existing daily provider-attempt guard and free database expiry. Aggregate counts measure validated initial server creations, not unique visitors, confirmed views or downloads. Unknown/unsupported visual requests should clarify rather than claim an asset was generated.
